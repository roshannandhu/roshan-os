# Feasibility Matrix

Status reflects verified Phase 0 evidence, not assumptions. A feature marked available still requires the stated validation before it is exposed in the controller.

| Feature                     | Status / provider                                          | Root needed                                   | Complexity | Reliability risk | Proposed implementation                                                       |
| --------------------------- | ---------------------------------------------------------- | --------------------------------------------- | ---------- | ---------------- | ----------------------------------------------------------------------------- |
| Live video                  | Available through IP Webcam; /video advertised             | No                                            | Medium     | Medium           | Proxy from controller API after controlled stream test.                       |
| Live listening audio        | Available through IP Webcam; WAV and Opus paths advertised | No                                            | Medium     | Medium           | Proxy selected audio format after playback test.                              |
| Rear camera                 | Hardware confirmed                                         | No                                            | Low        | Medium           | One active camera at a time through verified IP Webcam control.               |
| Front camera                | Hardware confirmed                                         | No                                            | Low        | Medium           | One active camera at a time through verified IP Webcam control.               |
| Remote camera switching     | Unknown                                                    | No                                            | Medium     | Medium           | Discover exact installed UI request; test only with approval.                 |
| Simultaneous cameras        | Unsupported                                                | N/A                                           | High       | High             | Exclude version one: camera service rejects concurrent second client.         |
| Torch                       | Not feasible on current hardware                           | No                                            | Low        | Low              | Hide as unavailable; both cameras report no flash unit.                       |
| Zoom                        | IP Webcam endpoint verified                                | No                                            | Low        | Medium           | Validate available range from status, then use typed zoom command.            |
| Focus                       | IP Webcam endpoints verified                               | No                                            | Low        | Medium           | Validate focus modes/range, then use typed command.                           |
| FPS                         | Hardware reports ranges; remote setting unverified         | No                                            | Medium     | Medium           | Verify accepted video configuration before implementation.                    |
| Resolution                  | IP Webcam generic video_size setting inferred from its UI  | No                                            | Medium     | Medium           | Read allowed values; validate against allowlist.                              |
| Quality                     | IP Webcam quality setting verified                         | No                                            | Low        | Low              | Validate integer range and issue typed request.                               |
| Snapshot                    | Interface resources exist; action path unverified          | No                                            | Low        | Low              | Discover UI request and add only if confirmed.                                |
| Push-to-talk                | Requires Companion Agent                                   | No for playback; root later only for recovery | High       | Medium           | Authenticated WebSocket, PCM/Opus frames, AudioTrack, hold-state machine.     |
| Tablet speaker playback     | Hardware route confirmed; requires Companion Agent         | No                                            | Medium     | Medium           | Android AudioTrack on media/speech route.                                     |
| Half-duplex switching       | Requires controller and Companion                          | No                                            | Medium     | Medium           | Mute incoming player while pointer is held; send talk-start/stop.             |
| Echo reduction              | Hardware-dependent, no AEC confirmed                       | No                                            | Medium     | High             | Half duplex, short restore delay, safe volume default, physical separation.   |
| Fullscreen text             | Requires Fully Kiosk or equivalent display adapter         | No                                            | Medium     | Low              | Host expiring message page; load through Fully adapter.                       |

| Video display               | Requires Fully Kiosk                                       | No                                            | Medium     | Medium           | Validate MIME/size; use H.264/AAC MP4 target.                                 |
| Webpage display             | Requires Fully Kiosk                                       | No                                            | Medium     | Medium           | HTTPS URL validation and optional expiry.                                     |
| Black screen                | Requires Fully Kiosk or Companion                          | Possibly                                      | Low        | Low              | Black page plus minimum brightness; physical off remains separate.            |
| Dashboard restore           | Requires Fully Kiosk                                       | No                                            | Low        | Low              | Fully loadStartUrl after installation and validation.                         |
| Brightness                  | Requires Fully Kiosk or Companion                          | Root fallback later                           | Low        | Medium           | Prefer verified normal API; allowlisted root fallback only after approval.    |
| Media volume                | Requires Fully Kiosk or Companion                          | Root fallback later                           | Low        | Low              | Clamp to observed device range and use verified adapter.                      |
| Mute/unmute                 | Requires Companion or Fully                                | No                                            | Low        | Low              | Store prior volume server-side only if needed.                                |

| Restart IP Webcam           | Existing automation can start it; API action needs root    | Yes                                           | Medium     | High             | Later fixed allowlist action only, manual test first.                         |

| Reboot                      | Root is available                                          | Yes                                           | Medium     | High             | Explicit confirmation plus fixed allowlisted command; no automatic reboot.    |

| Kiosk lockdown              | Requires Fully Kiosk PLUS evaluation                       | No for basic app use                          | Medium     | Medium           | Install/test free version first; no purchase or activation without approval.  |
| Casual uninstall prevention | Partially feasible                                         | Device admin/kiosk configuration              | Medium     | Medium           | Kiosk restrictions and recovery process; no claim of absolute protection.     |
